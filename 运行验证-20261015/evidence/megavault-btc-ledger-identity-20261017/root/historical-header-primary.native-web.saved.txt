L192: # Testnet Game Day # 1: 2024-Jan-24
L193: 
L194: For our first-ever game day, we will experiment with how we respond to changes during software upgrades. We will post announcements in the `testnet-announcements` channel in Discord to coordinate activities during the event.
L195: 
L196:   * Start time: `2024-01-24 14:30 UTC`
L197:   * Estimated end time: `2024-01-24 15:30 UTC`
L198: ## Recap
L199: 
L200:   * 39 validators participated
L201:   * The event runtime was exactly 1 hour
L202:   * Two software upgrades were scheduled
L203:     * One upgrade was canceled via governance with a `cancel-software-upgrade` proposal
L204:     * One upgrade was skipped via the `unsafe-skip-upgrades` flag
L205: ### Lessons learned & findings
L206:   * Votes for past proposals can be obtained by querying a block height when the proposal was still active.
L207:     * REST API: `curl “<API URL>/cosmos/gov/v1beta1/proposals/<proposal id>/votes?pagination.limit=1000” -H “x-cosmos-block-height:<height>”`
L208:     * Gaia CLI: `gaiad q gov votes <proposal id> --height <height>`
L209:   * The `--unsafe-skip-upgrades <block height>` flag can be seen as a last-resort mechanism for skipping an upgrade that is deemed unacceptable, but coordination is critical to make sure the chain does not halt when the upgrade height is reached.
L210:   * A cite73†Cosmovisor bug was found and reported by a validator when attempting to use the `add-upgrade` command.

L248: ## How to Join
L249: 
L250:   * ⚠️ Do NOT use your `provider` chain keys. Never reuse keys!
L251: ### Bash Script
L252: 
L253: Run either one of the scripts provided in this repo to join the provider chain:
L254: 
L255:   * `join-gameday01.sh` will create a `gaiad` service.
L256:   * `join-gameday01-cv.sh` will create a `cosmovisor` service.
L257:   * Both scripts must be run either as root or from a sudoer account.
L258:   * Both scripts will attempt to download the amd64 binary from the Gaia cite83†releases page. You can modify the `CHAIN_BINARY_URL` to match your target architecture if needed.
L259: ### Creating a Validator
L260: 
L261: Once you have some tokens in your self-delegation account, you can submit the `create-validator` transaction.
L262: Submit the `create-validator` transaction.
L263: 
L264:     gaiad tx staking create-validator \
L265:     --amount 1000000uatom \
L266:     --pubkey "$(gaiad tendermint show-validator)" \
L267:     --moniker <your moniker> \
L268:     --chain-id gameday01 \
L269:     --commission-rate 0.10 \
L270:     --commission-max-rate 1.00 \
L271:     --commission-max-change-rate 0.1 \
L272:     --gas auto \
L273:     --gas-adjustment 1.4 \
L274:     --gas-prices 0.005uatom \
L275:     --from <self-delegation-account>
